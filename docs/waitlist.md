# Cloud waitlist

dpdpkit Cloud is the hosted version of dpdpkit: the same consent ledger, notices, rights requests and
retention jobs, run for you, plus a hosted privacy portal on your own subdomain. An invite-only beta is
planned for mid-2027.

The open-source packages stay free and keep working without Cloud. Join the waitlist if you want:

- an invite to the Cloud beta,
- help implementing dpdpkit in your app (a readiness sprint), or
- to become a design partner: free setup help in exchange for feedback while the toolkit is young.

## Before you sign up

This form collects personal data, so here is the notice we would expect any dpdpkit user to show.

| | |
| --- | --- |
| **What we collect** | Your email address (required). Your organisation, stack and interests if you choose to add them. |
| **Why** | To email you about the Cloud beta, implementation help and the design-partner programme. Nothing else. |
| **What we don't do** | Sell your data, share it with anyone other than the form service named below, add you to other lists, or track you across sites. |
| **How long we keep it** | Until you withdraw, or 12 months after dpdpkit Cloud becomes generally available, whichever comes first. |
| **Withdraw** | Use the unsubscribe link in any email, or write to the address below. Withdrawing is as easy as signing up, and we delete your entry within 7 days. |
| **Your rights** | You can ask for a summary of what we hold, correct it, or have it erased. |

Signing up is optional and nothing in the form is pre-ticked. The form records which version of this
notice you saw.
