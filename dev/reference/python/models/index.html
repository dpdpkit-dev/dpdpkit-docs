    Not legal advice

    dpdpkit is software that helps you implement obligations under India's Digital Personal Data Protection Act, 2023 and the DPDP Rules, 2025. It does not provide legal advice and does not guarantee compliance.

    Models and errors¶

    Pydantic v2 models for every dpdpkit aggregate. Every model carries tenant_id.

    No ORM type ever crosses the repository boundary; adapters convert rows to these models.

    DEFAULT_TENANT module-attribute ¶

    DEFAULT_TENANT = 'default'

    OPEN_REQUEST_STATUSES module-attribute ¶

    OPEN_REQUEST_STATUSES = frozenset({RequestStatus.RECEIVED, RequestStatus.IDENTITY_PENDING, RequestStatus.IN_PROGRESS})
