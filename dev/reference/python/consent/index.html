    Not legal advice

    dpdpkit is software that helps you implement obligations under India's Digital Personal Data Protection Act, 2023 and the DPDP Rules, 2025. It does not provide legal advice and does not guarantee compliance.

    Record one decision per purpose, all against the same notice (no bundled consent).

    check ¶

    check(principal: str, purpose: str) -> bool

    True when processing for purpose is allowed for principal.

    Purposes with a Section 7 legitimate use do not need consent and always return True. Unknown purposes raise NotFound (a programming error, not a denial).

    build_content ¶

    build_content(*, title: str, links: Mapping[str, str], body: str = '', purposes: Mapping[str, Mapping[str, str]] | None = None) -> NoticeContent

    Itemise every registered purpose. purposes overrides title/description per purpose (for translations); data item names come from the registry.

    problems ¶

    problems(content: NoticeContent) -> list[str]

    Everything that stops this content from being published under the active policy.

    publish ¶

    publish(translations: Mapping[str, NoticeContent], *, actor: str = 'system') -> list[Notice]

    Publish a new notice version with one content per locale.

    The policy's default language must be present. Every locale must pass problems.
